Hisab — bundled font provenance

    NOT YET FETCHED.

This file is the placeholder committed with the source tree. Running
`./scripts/fetch-fonts.sh` on a machine with a network connection overwrites it
with the real record: source URL, sha256 and byte count for every face.

Why the binaries are not in this commit: the environment that wrote this story
had no route to raw.githubusercontent.com, and a font guessed from memory is a
tofu box in a shop owner's hand. CI fails loudly when the .ttf files are absent
rather than letting the build fall back to a system face (UX-DR3).

Sources
-----------------------------------------------------------------------------
  Hind Siliguri        github.com/google/fonts  ofl/hindsiliguri/
                       shipped upstream as static instances.
  Noto Serif Bengali   github.com/google/fonts  ofl/notoserifbengali/
                       shipped upstream as a variable face; the script instances
                       it to wght=600 and wght=700 at wdth=100 with fonttools,
                       because pubspec.yaml can only declare fixed filenames.
